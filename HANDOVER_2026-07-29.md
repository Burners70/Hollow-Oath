## One cross-bundle integration note for whoever eventually merges these

**Bundle X's training mode and Bundle Z's gravity system don't know about
each other.** `startTraining()` (`js/world.js`, X's branch) never resets
`gravScale`/`gravTilt`. If a player finishes a REMIX run (odd gravity) and
then opens the trainee sector, the tutorial would inherit whatever gravity
was last rolled — could make "hold THRUST and see it work" teach the wrong
thing. Fix is trivial (`gravScale = 1; gravTilt = 0;` in `startTraining()`)
but doesn't need doing until these two branches actually share a codebase —
don't preemptively patch code across branches that haven't merged.
